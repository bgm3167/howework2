# [모아테크] AI 회의록, 이 3가지는 꼭 다시 확인하세요

| 시간 | 화면 | 내레이션 | 자막 |
|---|---|---|---|
| 0~3초 | 썸네일 문구 없이, 손에 든 스마트폰의 자동 회의록과 원음 파형을 빠르게 교차한다. 회의록의 결정 사항 한 줄과 원음 재생 화면을 함께 보여준다. | AI가 정리했으니, 이 회의록 그대로 공유해도 될까요? | AI 회의록, 틀릴 수 있다고? |
| 3~12초 | 여러 사람이 겹쳐 말하는 회의 화면. 화자 1, 화자 2 라벨이 바뀌는 듯한 수정 전·후 화면을 보여준다. | 겹쳐 말하거나, 한 마이크를 함께 쓰거나, 음질이 나쁜 공간에서는 화자 구분이 어려울 수 있습니다. Otter도 이런 조건을 안내합니다. [출처](https://help.otter.ai/hc/en-us/articles/37817241040535-Best-Practices-to-Maximize-Speaker-Identification) | 겹쳐 말하기·잡음 = 화자 확인 |
| 12~22초 | 전문 용어가 포함된 전사문을 확대했다가, 원음과 다른 요약 문장이 삽입된 화면으로 전환한다. | 전문 용어 오인식만 문제가 아닙니다. 실제로 말하지 않은 내용이 기록되는 환각 사례도 보고됐습니다. [출처](https://www.adalovelaceinstitute.org/report/scribe-and-prejudice) | 전사 오류 + 요약 환각 |
| 22~29초 | 검수 1단계. 원음 파형과 전사문을 나란히 놓고 결정 사항 문장을 재생한다. | 첫째, 결정 사항과 후속 과제를 원음과 원문으로 대조하세요. | 1. 원음·원문 대조 |
| 29~35초 | 검수 2단계. 화자 라벨을 손가락으로 바꾸고 부정 표현에 형광 표시한다. | 둘째, 화자 이름과 ‘아니다’, ‘하지 않는다’ 같은 부정 표현을 확인하세요. | 2. 화자·부정 표현 확인 |
| 35~41초 | 검수 3단계. 요약문에서 발화하지 않은 일정과 담당자 항목을 삭제 전후로 보여준다. | 셋째, 실제 발화에 없던 일정, 담당자, 결정 사항이 추가되지 않았는지 살펴보세요. | 3. 임의 생성 여부 확인 |
| 41~47초 | 세 장면을 분할 화면으로 보여준다. 조용한 1~2인 회의, 여러 명이 겹쳐 말하는 회의, 민감한 고객 회의 순서다. | 조용한 회의라면 전사와 수정 편의성, 사람이 많으면 화자 분리, 민감한 내용이면 데이터 정책부터 비교하세요. | 환경별 선택 기준 |
| 47~50초 | 수정 전·후 회의록과 원음 파형을 함께 보여주며 블로그 화면으로 전환한다. | AI 회의록은 작성자가 아니라 검수 가능한 초안 도구입니다. 전체 비교 기준은 모아테크 블로그에서 확인하세요. | 검수 가능한 초안 도구 |
